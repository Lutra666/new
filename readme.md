# 鳌龙财务管理系统

面向批发零售企业的桌面级财务管理软件，支持商品管理、采购销售、库存跟踪、财务记账、AI 智能分析等核心 ERP 功能。基于 Electron 打包为 Windows 安装程序，开箱即用。

> 在线体验：**[ahut615.top/finance](https://ahut615.top/finance)** &nbsp;|&nbsp; 默认账号 `admin` / `admin123`

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | React 18 + Ant Design + react-router-dom + axios |
| 后端 | Node.js + Express + JWT 鉴权 (HS256) |
| AI | Anthropic SDK（兼容 DeepSeek API）+ SSE 流式响应 |
| 数据 | JSON 本地文件存储（默认）/ MySQL 8.0（可选） |
| 桌面 | Electron + electron-builder (NSIS 安装程序) |

## 快速开始

### 环境要求

- Node.js 18+
- npm 8+
- Windows 10/11（安装包仅支持 Windows x64）

### 开发模式启动

```bash
# 克隆仓库
git clone https://github.com/Lutra666/new.git
cd new

# 安装依赖并启动（推荐）
npm start
```

执行后自动：检查并安装依赖 → 启动后端 (端口 3001) → 启动前端 (端口 3000) → 打开浏览器访问 `http://localhost:3000`

```bash
# 仅启动后端
cd backend && npm start

# 仅启动前端（开发热更新）
cd frontend && npm start

# 构建 Windows 安装包 (.exe)
npm run dist:win
```

登录后建议立即修改密码：右上角头像 → 修改密码。

### 基本工作流

1. **录入基础资料**：添加商品、客户、供应商
2. **创建订单**：销售订单（出库）或采购订单（入库），选择商品后自动计算金额
3. **查看库存**：订单生效后库存自动更新，支持仓库间调拨
4. **财务管理**：记录收支流水，跟踪应收/应付账款
5. **数据备份**：系统设置 → 数据管理 → 创建备份（也支持自动定时备份）

### MySQL 模式配置（可选）

1. 创建 MySQL 数据库（UTF-8 编码）
2. 复制 `backend/.env.example` 为 `backend/.env`
3. 设置 `USE_REAL_DB=true`，填写 `DB_HOST / DB_PORT / DB_USER / DB_PASSWORD / DB_NAME`
4. 启动后端时会自动建表

## AI 智能分析

v1.0.9 起集成 AI 能力，通过 Anthropic SDK 对接 DeepSeek API（`deepseek-v4-pro` 模型），在侧边栏「AI 智能分析」入口使用。

### 四大功能

| 功能 | 说明 |
|------|------|
| **智能问答** | 用自然语言查询经营数据，例如"上个月销售额最高的商品是什么？"、"哪些客户还有未付款？"——AI 自动理解意图并返回分析结果。支持流式 SSE 响应，逐字输出体验。 |
| **智能报告** | 一键生成四类报告：**经营概况**（收入/成本/利润趋势）、**客户分析**（价值分层/复购率）、**库存健康度**（滞销/缺货预警）、**资金流向**（现金流结构）。报告支持 Markdown 渲染，可打印存档。 |
| **异常检测** | 自动扫描订单、库存和财务数据，识别三类异常：**高严重度**（负库存、重复订单号）、**中严重度**（库存低于预警线、应收超期）、**低严重度**（价格异常波动）。异常数量用颜色标记，点击展开详情。 |
| **经营建议** | 基于当前数据生成可操作的经营建议，支持按关注领域筛选（销售增长、成本控制、库存优化、资金效率、客户运营）。建议以聊天形式交互，持续追问可获得更深入的分析。 |

### AI 配置

```bash
# backend/.env 中添加
ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic  # API 地址
ANTHROPIC_API_KEY=sk-your-api-key-here                  # API 密钥
AI_MODEL=deepseek-v4-pro                                # 模型名称
AI_RATE_LIMIT_MAX=20                                    # 每 15 分钟请求上限
```

系统默认已配置 DeepSeek 兼容端点，也可替换为 Claude API 原生地址 `https://api.anthropic.com`。

### 技术特点

- **流式输出**：使用 SSE (Server-Sent Events) 实现打字机效果
- **上下文感知**：自动将当前系统数据（商品、订单、库存、财务）注入 AI 上下文
- **频率保护**：独立的 AI 请求限流器，防止 API 滥用
- **错误降级**：API 不可用时优雅提示，不影响其他功能正常使用

## 数据模式

系统支持双模式运行，通过 `backend/.env` 中的 `USE_REAL_DB` 切换：

- **本地模式（默认）**：数据存储在 `backend/data/mock-store.json`，单文件便携，已预置演示数据
- **MySQL 模式**：连接 MySQL 8.0，适合正式部署生产环境

## 安全特性

- JWT 令牌鉴权，支持 issuer/audience 校验
- 登录失败锁定机制（次数和时长可配置）
- 敏感字段 AES-256-GCM 加密存储
- 备份文件 HMAC 签名校验防篡改
- 生产环境强制要求安全 JWT_SECRET
- Electron 沙箱模式 + 导航白名单

## 环境配置

复制 `backend/.env.example` 为 `backend/.env`：

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `USE_REAL_DB` | 数据库模式 | `false` |
| `JWT_SECRET` | JWT 签名密钥 | — |
| `DEFAULT_ADMIN_PASSWORD` | admin 初始密码 | `admin123` |
| `BIND_HOST` | 绑定的 IP 地址 | `127.0.0.1` |
| `AUTO_BACKUP_ENABLED` | 自动备份开关 | `true` |
| `AUTO_BACKUP_INTERVAL_MINUTES` | 备份间隔 | `1440` |
| `ANTHROPIC_API_KEY` | AI 功能 API 密钥 | — |
