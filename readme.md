# 鳌龙财务管理系统

面向批发零售企业的桌面级财务管理软件，支持商品管理、采购销售、库存跟踪、财务记账等核心 ERP 功能。基于 Electron 打包为 Windows 安装程序，开箱即用。已部署上线：**[ahut615.top/finance](https://ahut615.top/finance)**

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | React 18 + Ant Design + react-router-dom + axios |
| 后端 | Node.js + Express + JWT 鉴权 (HS256) |
| 数据 | JSON 本地文件存储（默认）/ MySQL 8.0（可选） |
| 桌面 | Electron + electron-builder (NSIS 安装程序) |

## 快速开始

### 环境要求

- Node.js 18+
- npm 8+
- Windows 10/11（安装包仅支持 Windows x64）

### 开发模式启动

```bash
# 克隆仓库
git clone https://github.com/Lutra666/new.git
cd new

# 安装依赖并启动（推荐）
npm start
```

执行后自动：检查并安装依赖 → 启动后端 (端口 3001) → 启动前端 (端口 3000) → 打开浏览器访问 `http://localhost:3000`

```bash
# 仅启动后端
cd backend && npm start

# 仅启动前端（开发热更新）
cd frontend && npm start

# 构建 Windows 安装包 (.exe)
npm run dist:win
```

### 基本工作流

1. **录入基础资料**：添加商品、客户、供应商
2. **创建订单**：销售订单（出库）或采购订单（入库），选择商品后自动计算金额
3. **查看库存**：订单生效后库存自动更新，支持仓库间调拨
4. **财务管理**：记录收支流水，跟踪应收/应付账款
5. **数据备份**：系统设置 → 数据管理 → 创建备份（也支持自动定时备份）

### MySQL 模式配置（可选）

1. 创建 MySQL 数据库（UTF-8 编码）
2. 复制 `backend/.env.example` 为 `backend/.env`
3. 设置 `USE_REAL_DB=true`，填写 `DB_HOST / DB_PORT / DB_USER / DB_PASSWORD / DB_NAME`
4. 启动后端时会自动建表

## 功能模块

| 模块 | 功能说明 |
|------|---------|
| **商品管理** | 商品名称、分类（粮油调味/乳品饮料/日用百货等）、单价、单位、规格型号 |
| **客户管理** | 客户名称、联系人、电话、等级（A/B/C）、应收余额 |
| **供应商管理** | 供应商名称、联系人、电话、应付余额 |
| **销售订单** | 选择客户和商品自动生成订单，支持多商品行、数量联动、金额自动计算、库存不足拒绝出库 |
| **采购订单** | 选择供应商和商品，入库后自动增加库存 |
| **库存管理** | 实时库存数量、安全库存预警、仓库间调拨、按商品/仓库检索 |
| **财务管理** | 收入/支出记账、账户余额（现金/银行/应收/应付）、交易流水 |
| **数据报表** | 累计销售额、累计利润、库存总件数、客户总数、热销商品排行 |
| **系统管理** | 用户账号增删改、角色权限（管理员/操作员/观察者）、操作审计日志、系统诊断面板 |
| **数据备份** | 一键创建备份、恢复历史备份、自动定时备份、备份签名校验防篡改 |
| **暗色模式** | 一键切换亮色/暗色主题，带有从按钮向外扩散的过渡动画 |

## 数据模式

系统支持双模式运行，通过 `backend/.env` 中的 `USE_REAL_DB` 切换：

- **本地模式（默认）**：数据存储在 `backend/data/mock-store.json`，单文件便携，已预置演示数据
- **MySQL 模式**：连接 MySQL 8.0，适合正式部署生产环境

## 安全特性

- JWT 令牌鉴权，支持 issuer/audience 校验
- 登录失败锁定机制（次数和时长可配置）
- 敏感字段 AES-256-GCM 加密存储
- 备份文件 HMAC 签名校验防篡改
- 生产环境强制要求安全 JWT_SECRET
- Electron 沙箱模式运行

## 环境配置

复制 `backend/.env.example` 为 `backend/.env`：

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `USE_REAL_DB` | 数据库模式 | `false` |
| `JWT_SECRET` | JWT 签名密钥 | — |
| `DEFAULT_ADMIN_PASSWORD` | admin 初始密码 | `admin123` |
| `BIND_HOST` | 绑定的 IP 地址 | `127.0.0.1` |
| `AUTO_BACKUP_ENABLED` | 自动备份开关 | `true` |
| `AUTO_BACKUP_INTERVAL_MINUTES` | 备份间隔 | `1440` |
